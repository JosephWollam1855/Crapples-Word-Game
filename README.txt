Outcome 2: Solved in 5–6 guesses — the original man in orange T-shirt and fishing cap. (NOT the subsequently rejected Packers images.)
Outcome 3: Not solved in six guesses — the woman in the black Angry Jo's shirt.

All outcome headings and description text remain exactly the same as V13.
Daily Challenge, unlimited practice, existing menu artwork, and word rules remain unchanged.

Install on PC:
1. Extract this ZIP.
2. Copy ALL SEVEN files (index.html + 6 .webp images) into your existing Crapples folder, replacing existing files when asked.
3. Double-click index.html to play.

To publish: upload all seven game files to your existing Crapple's GitHub repository and commit. Your Render static site can deploy the update from GitHub.

Images appear in the result popup after a completed puzzle; they do not replace the main-menu artwork.
